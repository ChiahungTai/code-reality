# CR usage investigation (2026-09-26)

`report.md` is the finalized investigation report; `axis-{a,b,c}.md` are the
three evidence axes and `tri-{a,b,c}.md` the adversarial triage rounds it
synthesizes (all referenced from the report).

The machine-readable evidence (`window-jobs*.json`, `usage-detail.json`,
`auto-inj.json`, `manual-inj.json`) is deliberately NOT published here: it is
a derived copy of per-repo delegate-bridge job ledgers (including raw session
prompts from other workspaces) and stays out of this public repository. The
authoritative sources remain in each repo's `.delegate-bridge/jobs/` ledger.
